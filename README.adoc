= TOTP (Time-based One Time Passcode)-backed Passwordless Auth in PHP Using Twilio Verify PHP

This project shows how to implement passwordless authentication in PHP with TOTP using Twilio Verify.

== Prerequisites

You'll need the following to use the application:

* PHP 8.4 or above
* https://getcomposer.org[Composer] installed globally
* Your preferred code editor or IDE
* Some terminal experience is helpful, though not required
